# timer

A minimal timer with two modes in one page, `index.html`.

- **Pomodoro**: focus, short break, and long break sessions that cycle automatically. Optional live radio, deep pink noise, and sound cues.
- **Interval**: repeating work and break intervals with presets (30 sec, 1 min, 10 min), custom lengths, a round limit, sound and flash alerts, and a screen wake lock.

Both modes share a light and dark theme, a settings dialog, and saved preferences. Space starts or pauses. R resets.

Live radio loads a YouTube embed, so serve the page over HTTP or HTTPS rather than opening the file directly.
